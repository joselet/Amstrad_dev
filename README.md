# amstrad_dev

Desarrollo para Amstrad CPC. Tres proyectos independientes:

| Carpeta | Contenido |
|---|---|
| [`Amstrad_asm/`](Amstrad_asm/) | Curso de ensamblador Z80 paso a paso (RASM + Caprice32, en Windows) |
| [`Amstrad_dev_cpctelera/`](Amstrad_dev_cpctelera/) | Programas en BASIC y en C/ensamblador con CPCtelera (en WSL) |
| [`Amstrad_os/`](Amstrad_os/) | Sistema operativo propio sin firmware y gestor de ficheros para la placa M4 (RASM + Caprice32) |

Cada carpeta tiene su propio `README.md` con la instalación y el uso.
